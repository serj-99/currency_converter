# Конвертер валют для Firefox

Нажмите кнопку расширения на панели Firefox, введите сумму и выберите исходную валюту. Результаты для остальных выбранных валют появятся сразу. Нажмите шестерёнку, чтобы добавить или убрать валюты из списка Банка России. Выбор сохраняется между открытиями окна; нужно оставить минимум две валюты.

Курсы загружаются при каждом открытии окна из [официального сервиса Банка России](https://www.cbr.ru/development/sxml/). Курс тенге приводится к одной единице с учётом номинала, указанного Банком России. Для работы нужен интернет.
