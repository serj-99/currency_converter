# Конвертер валют для Firefox

Нажмите кнопку расширения на панели Firefox, введите сумму и выберите исходную валюту. Результаты для трёх остальных валют появятся сразу.

Курсы загружаются при каждом открытии окна из [Frankfurter](https://frankfurter.dev/) и обычно обновляются раз в день. Для работы нужен интернет.

## Проверка в Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение».
3. Выберите `manifest.json` из этой папки.

Временное дополнение исчезнет после перезапуска Firefox. Для постоянной установки потребуется подписать расширение через Mozilla Add-ons.
